# 视觉效果接入位置

按 design.md 的职责逐项制作。当前实际接入：

- `DotText.tsx`：沿用根目录 `交互效果/dot-text/` 的取样、局部排斥与回弹参数，应用于页尾宋体文字；离屏、后台、减少动态效果与普通文字回退已处理。
- `FlowerScene.tsx`：按需加载确认模型导出的 GLB，三组网格应用品牌网点 shader；轻微指针视角响应、demand 渲染、静态 PNG 回退由首页结合处理。
- `GrowthStage.tsx`：同一株植物的五段原生渲染，进入视野后播放一次；窄屏或减少动态效果使用匹配镜头的透明关键帧。
- 滚动与切换：Motion，尊重减少动态效果。
- 花束与粒子：Three.js + React Three Fiber + Drei，配合优化的网页模型、延迟加载与静态回退。
- ASCII：按实际画面需要探索 Drei 的渲染工具，保持内容可读。

源模型位于 `素材/桔梗/连续生长-v2/`，网页导出件位于 `public/flowers/`。没有用替代几何体冒充桔梗；当前网点材质与生长短片不代表已实现浏览器内运动点云或实时几何生长。
